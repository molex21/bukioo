# Skills de terceros

Las skills de `.agents/skills/` son material de sus respectivos autores;
su presencia no cambia la licencia propia de BUKIOO. Instaladas desde `main`
el 17/10/2026, sin registrar el hash exacto. Antes de actualizar una skill,
revisar su origen, cambios, permisos y compatibilidad.

- `design-taste-frontend`: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill),
  licencia MIT; aviso completo más abajo.
- `web-design-guidelines`: [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills),
  cuyo README declara MIT. No se encontró un archivo de licencia o aviso de
  copyright independiente en la raíz del repositorio consultada; verificar
  atribución y condiciones antes de distribuir esta copia.
- `playwright-cli`: [microsoft/playwright-cli](https://github.com/microsoft/playwright-cli),
  Apache-2.0. El texto se incluye en `docs/licenses/Apache-2.0.txt`.

El instalador copia la carpeta de cada skill, no las licencias de la raíz de
sus repositorios. Conservar estos avisos con las skills si se comparten o se
incluyen en un commit y revisar si hay avisos adicionales de terceros.
