# Especificaciones de BUKIOO

BUKIOO es un SaaS multiempresa para gestionar citas, clientes y negocios de
servicios. Su frontend utiliza React, TypeScript, Vite y Mantine; el backend
utiliza NestJS y PostgreSQL con SQL parametrizado y migraciones dbmate.

Esta carpeta contiene especificaciones de funcionalidades en desarrollo.
Cada bloque separa requisitos (spec.md), diseño de implementación (plan.md)
y seguimiento de tareas (tasks.md). Su presencia no implica que la función
esté implementada.

Las áreas descritas incluyen catálogo de servicios, gestión de empleados,
asignaciones y calendario laboral, usuarios y permisos, seguridad de acceso,
tarifas de mano de obra y accesibilidad.

La presentación, instalación y ejecución del proyecto están en el
[README principal](../README.md). El estado de las funcionalidades se recoge en
el [roadmap del frontend](../frontend/FRONTEND_ROADMAP.md).
